# Zoe G. del Toro — personal research website

An editorial research archive for Zoe G. del Toro, PhD candidate in mathematical
quantum information theory at LIP6, Sorbonne Université.

## Publish on GitHub Pages

1. Copy these files into the `zoegdt.github.io` repository.
2. Commit them and push to the `main` branch.
3. In GitHub, open **Settings → Pages** and set **Source** to **GitHub Actions**.
4. The included workflow publishes the site automatically after each push.

The live address is `https://zoegdt.github.io/`.

## Edit later

- Main text and publication records: `index.html`
- Colours, typography, and responsive layout: `styles.css`
- Theme switch and reveal transitions: `script.js`
- Portrait, CV, and social preview: `assets/`

The page includes links to email, LinkedIn, ORCID, and Google Scholar, together
with structured profile metadata and a sitemap for search-engine discovery.
